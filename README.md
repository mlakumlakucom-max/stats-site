**DataNusa — Statistik Indonesia.** A national statistics site for Indonesia, built from official published figures (BPS and the Ministry of Health), with every figure labelled with its source and year. Homepage with key indicators and a population chart; pages for population, economy, all 38 provinces (searchable, sortable table), education, and health; plus a methodology page listing every source. Static files only — no build step, no network requests, works offline on desktop and phone. Charts are drawn with the site's own SVG code.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
